# 🕹️ Pong Game (Web)

A classic Pong game built using **HTML, CSS, and JavaScript**. This simple web-based arcade game demonstrates DOM manipulation, animations, and responsive gameplay — perfect for practicing front-end fundamentals and game logic.

---

## 🚀 Features

- Two-player Pong gameplay (left vs right)
- Ball collision detection with paddles and walls
- Score tracking system
- Smooth movement and realistic rebound logic
- Simple, responsive layout using CSS
- Clean and modular JavaScript for easy understanding

---

## 🧰 Technologies Used

- HTML5 for structure
- CSS3 for layout and styling
- Vanilla JavaScript for game logic, animation, and event handling

---

pong-game/

└── README.md           # Project overview and usage

---

## ▶️ How to Run

1. Open `index.html` in any modern web browser.
2. Use keyboard keys (e.g., `W/S` for left paddle, `Arrow Up/Down` for right paddle).
3. First to reach the set score wins!
